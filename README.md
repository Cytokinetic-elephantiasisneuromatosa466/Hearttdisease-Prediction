## 📌 Overview

Hearttdisease-Prediction is a web app that helps you check the chance of heart disease from basic health details. It uses a simple form, then runs a machine learning model in the background to give a prediction.

The app runs in a web browser on Windows. You do not need coding skills to use it. You only need to download the release file, open the app, and enter the requested health values.

## ✨ What the app does

- Shows a simple home page with a clear purpose
- Lets you enter common health details
- Checks your input before you submit it
- Uses a Decision Tree model to make a prediction
- Displays the result on screen in a clear format

## 🧾 How to use the form

The form may ask for details such as:

- Age
- Sex
- Chest pain type
- Resting blood pressure
- Cholesterol level
- Fasting blood sugar
- Resting ECG result
- Maximum heart rate
- Exercise-induced angina
- Oldpeak value
- Number of major vessels
- Thalassemia value

Enter the values as shown on your health record or as instructed on the page. If the form uses drop-down lists, choose the option that matches your data.

## 🔎 Input tips

- Use only numbers where the form asks for numbers
- Choose one option in each drop-down list
- Check for empty fields before you submit
- Match the values to the labels on the form
- Do not guess if you are unsure about a value

The validation on the page helps catch common mistakes before the app sends the data.

## 🧩 How it works

The project has two main parts:

- **Frontend:** Built with HTML, CSS, and JavaScript
- **Backend:** Built with Flask
- **Model:** Uses a Decision Tree machine learning algorithm

When you submit the form, the browser sends the data to the Flask app. The model then checks the input and returns a prediction result.

## 🖥️ Troubleshooting

### The file will not open
- Right-click the file and choose Open
- Check that Windows did not block the file
- Try running the file as admin

### The browser does not show the app
- Wait a few seconds for the local server to start
- Refresh the page
- Check that the app window is still running

### The form does not submit
- Make sure every required field has a value
- Check number fields for letters or symbols
- Select one option in each drop-down list

### The page looks broken
- Refresh the page
- Try another browser
- Clear the browser cache
